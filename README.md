# Assurance Risque

Plateforme intelligente d'analyse et de prédiction des risques en assurance automobile.

## Objectifs

- Analyse statistique des contrats.
- Prédiction de la probabilité de sinistre.
- Explication des facteurs de risque.
- Estimation du coût attendu.
- Développement d'une plateforme web avec Django.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Django
- PostgreSQL (plus tard)
